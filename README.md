# ⚡ Cyberpunk PCB Necklace | Wearable Tech by Noberto

Welcome to the official repository of the **Cyberpunk PCB Necklace**, an original wearable hardware project developed under my independent brand, **Noberto**. This project merges electrical engineering, surface-mount technology (SMT), and cyberpunk aesthetics into a unique fashion accessory.

## 👁️ About the Project
This necklace is not just a piece of jewelry—it is a functional, custom-designed Printed Circuit Board (PCB). It features an onboard circuit designed to power and control micro LEDs, creating a bright, futuristic aesthetic that stands out in any environment, especially at night.

## 🔬 Technical Specifications
* **Form Factor:** Custom-shaped wearable PCB
* **Components:** 100% Hand-soldered SMD architecture
* **Power Supply:** CR2032 Coin Cell Battery (integrated metal/plastic holder)
* **Control:** Ultra-small built-in slide switch for easy on/off toggle
* **Safety:** Hypoallergenic materials chosen for safe daily wear

## 🎨 Design Features
* **Exposed Copper:** The "Noberto" branding is integrated directly into the hardware by removing the solder mask layer, exposing the raw copper underneath for a premium, industrial aesthetic.
* **Optimized Circuitry:** Designed from scratch to balance current consumption and LED brightness, ensuring maximum battery life without losing the cyberpunk glow.
